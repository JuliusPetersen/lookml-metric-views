LookML to metric views
Product notes Source on GitHub

Move Looker's metric definitions into Unity Catalog, and see exactly what still needs a person.

As of November 2026, Databricks' import tools list Tableau and Power BI as sources for metric views, not Looker. This tool turns every Looker explore into one metric view with its joins, and marks each field: exact, adapted, review or manual.

Convert a project

The conversion runs in your browser with Python (Pyodide). Your LookML is not sent anywhere except the GitHub download you ask for.
